# Painel de Rotinas — Grupo Cavalca

Painel colaborativo para acompanhamento de rotinas contábeis, com autenticação, atualização de status, comentários, registros de ações e histórico em tempo real.

## Acesso

Após a publicação no GitHub Pages, o painel estará disponível em:

https://tuliodubiella-arch.github.io/painel-rotinas-grupo-cavalca/

## Tecnologia

- HTML, CSS e JavaScript
- Supabase Auth, Postgres e Realtime
- SheetJS para importação e exportação de Excel
- Chart.js para gráficos

A chave presente no código é uma chave publicável do Supabase. Os dados permanecem protegidos por autenticação e Row Level Security.
